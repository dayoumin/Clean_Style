# 내 행동·일터 존중 v0.3.0  ·  구현·근거·결정 기록

결정·구현일 2026-10-15 · 기관 내부 시험용 · 공개 운영 승인·배포는 수행하지 않음

**최신 안내 개정 r2 · 2026-10-15:** r1의 다섯 수정에 이어 N1~N4와 D1·D2를 반영했다. 경험 20번 도움말(N5)은 유지했다. [최신 외부 AI 재검토용 Markdown](workplace-respect-external-ai-review-v03-r2-20261015.md). 공식 문항·배점·안전 분기와 도구·채점 버전은 유지한다. 11절은 r1 이력이고 최신 내용은 12절이다.

**현재 구현의 기준 문서.** 사용자의 최종 지시에 따라 내 행동은 2019년 공식 10문항·응답·채점·원표 구간을 그대로 적용했다. 일터 존중은 2026년 공식 경험 25문항·최근 6개월·빈도 응답을 유지하고 자체 0~4점 코딩·0~100점 시험 합계를 적용했다. 경험 위험 등급은 보류한다. 안전·도움 확인은 별도이며 합계·원표 구간을 바꾸지 않는다.

| 항목 | 내 행동 | 일터 존중 |

25개 합계는 종류와 빈도 범주를 함께 합한 요약값이다. 응답 범주 간 실제 횟수·피해 간격이 같다고 가정할 근거는 없으며 같은 사건이 여러 문항에 반영될 수 있다. 두 점검의 점수는 합치거나 서로 비교하지 않는다.

## 4. 안전·도움·AI·저장

- 기존 A11 신체 안전, E11 신체 안전·E10 마음건강 확인 문항·선택지·분기를 유지했다. 공식 10/25개의 문항 번호·진행률에는 포함하지 않고 ‘안전·도움 확인’으로 구분한다. 응답은 두 합계·원표 구간을 변경하지 않는다.

- 기존 즉시 도움 응답은 문항 완료를 요구하지 않고 사람·긴급 도움으로 연결한다. 안전 불확실·마음건강 도움 응답도 그 자리에서 도움을 제공한다. 경험 설문 14·25번의 과거 경험 빈도를 현재 위기로 자동 전환하지 않는다.

- 모든 질문에서 상담 안내와 기존 긴급 도움 경로에 접근할 수 있다. 결과에서도 별도 도움 영역을 유지한다. 점수가 낮거나 미산출이어도 접근 가능하다.

- 새 임상 문항·긴급 경계값을 만들지 않았다. 과거 폭력·상해와 현재 위험의 구분 등 기존 안전 쟁점은 전문가 확인 대기로 유지한다.

- AI에 기존 6축·등급 대신 새 점수 종류·합계 또는 미산출·원표 구간 또는 경험 등급 보류를 전달한다. AI가 등급·법적 판단·피해 심각성을 만들어내지 않도록 지침을 갱신했다. 실제 외부 AI의 응답 안전성까지 이번 모의 호출 검사로 승인하지 않는다.

- 이전 30분 탭 저장·만료·삭제·AI 요청 시 전송 고지 정책을 유지한다. 기관 자동 신고나 응답의 외부 연구자 전송은 추가하지 않았다.

## 5. 버전·호환성

문항 `v0.3.0`, 도구 `workplace-respect-official-v0.3.0`, 채점 `opm2019-10-moel2026-25-pilot-v1`. 저장 구조는 `workplace-respect-response-v1`의 안정적 문항·선택지 ID를 유지한다. 공식 문항 ID는 `OPM19-A01…A10`, `MOEL26-E01…E25`로 구별하고 기존 도움 문항 ID는 유지했다.

구 문항·채점 버전의 응답을 새 점수로 재해석하지 않고 거절·정리한다. 배열 순서가 바뀌어도 ID로 복원한다. 기존처럼 완성 응답 또는 첫 위기 응답에서 끝나는 연속 앞부분만 저장·AI 요청에 사용한다. 모름·건너뛰기를 명시한 완성 응답은 저장하되 점수는 미산출한다.
