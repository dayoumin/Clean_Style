청렴 성향 척도 타당화 계획

Clean Style을 자기성찰 테스트에서 타당화된 청렴 의사결정 성향 척도(validated scale) 후보로 올리기 위한 실행 계획이다. 기존 문서 검토 결과, 이론적 근거는 상당히 축적되어 있으나 표본 기반 검증은 아직 시작 전 단계로 본다.

Sections

1. 기존 문서 검토

기존 문서는 "왜 3축이 의미 있는가"를 설명하는 데 강하고, "현재 앱 문항이 실제로 3축 구조를 재현하는가"는 아직 검증 과제로 남겨 두고 있다. 따라서 새 계획은 이론 검토를 반복하지 않고, 표본 수집과 통계 검증을 실제 작업으로 바꾸는 데 집중한다.

3축 모델의 이론적 근거 및 타당화 설계 보고서

현재 모델의 핵심 한계를 이미 명시한다. 경험적 요인 구조 미검증, 파일럿 데이터 미확보, 준거 타당도 미검증이 높은 위험으로 분류되어 있다.

청렴 설문도구 정리

DIT-2, MCT/MJT, MES, EDM-CS 등 외부 척도 후보와 신뢰도 정보를 정리한다. Clean Style 검증의 비교 기준으로 활용한다.

원칙 & 유연성

원칙-유연성 축의 이론적 근거와 한계를 정리한다. 특히 자기보고식 편향과 한국 맥락 재타당화 필요성이 중요하다.

투명성 & 신중성

즉시 보고와 충분한 확인의 긴장을 조직 윤리와 리스크 관리 관점에서 설명한다. 문항 설계 시 "투명=무조건 선"으로 흐르지 않게 하는 근거가 된다.

독립 & 협력

독립-협력 축의 심리측정적 독립성을 정리하지만, 현재 앱의 단일 양극축 단순화는 파일럿 데이터로 확인해야 한다고 본다.

Scoring & Validity

현재 앱은 과학적 진단 도구가 아니라 자기발견 및 교육 보조 도구라고 명시한다. 이 포지셔닝은 타당화 완료 전까지 유지한다.

2. 목표와 경계

구분현재목표
사용 목적 자기성찰, 교육 대화 시작점 청렴 의사결정 성향의 연구·교육용 측정
금지 목적 인사평가, 선발, 징계 판단 타당화 후에도 선발·징계에는 별도 윤리심의와 법무 검토 전까지 사용 금지
결과 표현 8유형 중심 설명 3축 연속 점수 + 안정도 + 가장 가까운 프로파일
증거 수준 이론적 근거와 로직 검증 신뢰도(reliability), 구성 타당도(construct validity), 준거 타당도(criterion validity) 확보
"진단"이라는 표현은 검증 완료 전에는 쓰지 않는다. 외부 설명에서는 "청렴 의사결정 성향 검사", "성향 프로파일", "자기성찰 테스트"를 우선 사용한다.

3. 현재 앱 업데이트 원칙

여기서 "현재 결과를 업데이트한다"는 뜻은 현재 앱의 계산식을 곧바로 과학적 진단 점수로 바꾼다는 의미가 아니다. 검증 전까지 현재 앱은 자기성찰 도구로 유지하고, 연구용 검증 도구는 별도 경로로 만든다.

시점앱에서 바꾸는 것바꾸지 않는 것
지금 결과 설명의 표현 수위를 낮춘다. "확정 진단"이 아니라 "현재 응답 기준의 가장 가까운 성향 프로파일"로 설명한다. 15문항 계산 로직과 8유형 산출 방식은 유지한다.
파일럿 후 문항별 편향, 축간 공변, 경계형 비율을 보고 문항 후보를 수정한다. 검증 전에는 백분위나 규준 점수처럼 보이는 표현을 추가하지 않는다.
본조사 후 연속 축 점수, 결과 안정도, 경계형, 규준 백분위를 도입할지 결정한다. 8유형은 독립 검증 전까지 확정 분류가 아니라 설명용 프로파일로 취급한다.
운영 원칙: 현재 사용자에게는 "당신은 이 유형이다"보다 "이번 응답에서는 이 프로파일에 가장 가깝다"라고 설명한다.

4. 측정 모델 결정

현재 앱은 15개 시나리오의 4지선다 강제선택형(forced-choice) 구조다. 이 형식의 응답을 일반 리커트 척도처럼 바로 요인분석하거나 alpha/omega로 해석하면 선택지 간 의존성과 다축 점수 코딩 때문에 왜곡이 생길 수 있다. 따라서 표본 수집 전에 연구용 문항 형식을 먼저 결정한다.

선택지장점검증 방식판단
현재 강제선택형 유지 사용자 경험과 가장 일치한다. 선택지 수준 다항모형, IRT 계열 모델, 프로파일 안정도, 재검사 일치율을 우선 검토한다. 앱 경험 검증용으로 적합하나 분석 난도가 높다.
시나리오별 평정형 같은 시나리오 안에서 여러 반응 경향을 독립적으로 측정할 수 있다. EFA/CFA, alpha/omega, 측정 동치성 분석이 상대적으로 자연스럽다. 연구용 타당화 도구의 1차 후보로 둔다.
리커트형 진술문 축별 문항 수 확보와 신뢰도 산출이 쉽다. 전통적 척도 개발 절차를 적용한다. 성향 기반 보조 척도로 사용하고, 앱의 시나리오 결과와 연결한다.
결정 게이트: Phase 0 종료 전 연구용 주 문항 형식을 하나로 정한다. 형식이 정해지기 전에는 CFA, alpha/omega, 백분위 규준을 확정 계획으로 쓰지 않는다.

5. 연구윤리와 개인정보

공공기관 또는 연구기관 구성원을 대상으로 성향 자료를 수집하면 응답 강제, 조직 내 식별, 인사평가 오용 위험이 생긴다. 따라서 아래 항목은 파일럿 전에 준비해야 하는 선행 조건이다.

  • 참여 동의서: 연구 목적, 자발 참여, 중도 철회, 불이익 없음, 결과 사용 범위를 명시한다.
  • 개인정보 최소화: 직급·직무·기관 유형은 분석 목적에 필요한 수준으로 범주화하고, 소수 집단 재식별 위험을 점검한다.
  • 재검사 식별자: 이메일이나 사번 대신 별도 난수 코드 또는 응답자 생성 코드를 사용한다.
  • 보관·삭제: 원자료, 분석자료, 보고자료의 보관 기간과 삭제 기준을 사전에 정한다.
  • 직장 내 강제성 방지: 기관 단위 배포 시 상급자가 개별 참여 여부와 결과를 알 수 없게 한다.
  • 윤리심의: 외부 발표, 논문화, 기관 표본 수집이 예정되면 IRB 또는 이에 준하는 연구윤리 검토를 받는다.

6. 단계별 실행 계획

Phase 0
준비

목표 현재 15문항을 기준선으로 고정하고, 연구용 문항 풀과 측정 모델을 별도로 확정한다.

  • 각 축의 조작적 정의와 제외 기준을 1페이지로 고정한다.
  • 연구용 주 문항 형식과 분석 모델을 결정한다. 강제선택형 유지 여부를 이 단계에서 확정한다.
  • 동의서, 개인정보 최소화, 재검사 식별자, 데이터 보관·삭제 기준을 만든다.
  • 현재 문항 매핑표를 만들고, 선택지별 사회적 바람직성 편향을 표시한다.
  • 연구용 후보 문항을 45~60개로 확장한다. 최종 앱 문항과 연구 문항은 분리 관리한다.
Phase 1
전문가 검토

목표 내용 타당도(content validity)를 수치화한다.

  • 청렴·공직윤리, 조직심리, 통계/측정, 현장 실무자 각 1명 이상을 섭외한다.
  • 문항-축 적합도, 선택지 균형, 정답처럼 보이는 표현, 법 위반 선택지 오해 가능성을 평가한다.
  • 문항별 CVI(Content Validity Index)를 산출하고 낮은 문항은 수정 또는 제거한다.
Phase 2
파일럿

목표 문항 작동 여부를 빠르게 확인한다.

  • 권장 표본: 최소 n=200, 가능하면 n=300 이상.
  • 대상: 공공 연구기관 종사자를 1차 목표 모집단으로 두고, 직무군과 직급이 한쪽으로 몰리지 않게 모집한다.
  • 분석: 응답 분포, 문항 난이도, 문항-총점 관계, 축간 상관, 측정 형식에 맞는 탐색 분석을 수행한다.
  • 자료 품질: 미완료, 과도하게 짧은 응답 시간, 동일 패턴 반복, 주의확인 문항 실패 기준을 사전에 정한다.
  • 삭제 후보: 한 선택지에 80% 이상 몰리는 문항, 특정 축과 반대로 움직이는 문항, 축간 공변을 과도하게 만드는 문항.
Phase 3
본조사

목표 3축 구조와 외부 기준과의 관계를 검증한다.

  • 권장 표본: n=500~1,000. 직무군, 직급, 기관 유형을 기록한다.
  • 표본 설계: 가능하면 EFA용 표본과 CFA용 표본을 분리하고, 집단 비교가 필요한 하위집단은 최소 표본 기준을 사전에 정한다.
  • 확인 분석: 문항 형식에 맞는 CFA 또는 대안 잠재모형으로 3축 모형, 6하위축 모형, 대안 모형을 비교한다.
  • 비교 척도: HEXACO 일부 하위척도, EPQ/EPQ-5, SCS, ECQ, DIT-2 또는 MCT/MJT 중 사용권과 목적이 맞는 도구.
  • 준거 변수: 내부 신고 의향, 적극행정 의향, 절차 준수 성향, 조직 청렴도 인식, 사회적 바람직성 척도.
  • 공통방법 편향 보완: 행동 시나리오 선택, 교육 전후 변화, 알려진 집단 비교, 가능한 경우 외부 평정을 추가한다.
Phase 4
재검사

목표 결과 안정성을 확인한다.

  • 2~4주 간격으로 같은 응답자 일부를 재측정한다.
  • 축 점수의 검사-재검사 신뢰도(test-retest reliability)를 산출한다.
  • 8유형 변경률과 경계형 비율을 함께 보고한다.
Phase 5
운영 전환

목표 앱 결과 표현을 검증 증거 수준에 맞게 바꾼다.

  • 연속 점수, 백분위, 경계형, 결과 안정도 문구를 도입한다.
  • 8유형은 확정 판정이 아니라 "가장 가까운 프로파일"로 표시한다.
  • 검증 보고서, 사용 제한, 개인정보 처리 기준을 함께 공개한다.

7. 분석 설계

검증 항목최소 기준판단
문항 형식 적합성 강제선택형, 시나리오 평정형, 리커트형 중 확정된 형식에 맞는 분석 모델을 사용한다. 형식과 분석 모델이 맞지 않으면 표본 수집 또는 분석을 중단한다.
내적 일관성 평정형 또는 리커트형 문항에는 축별 Cronbach's alpha 또는 omega를 산출한다. 강제선택형에는 적합한 대안 신뢰도 지표를 사용한다. 낮으면 문항 확대 또는 축 정의 재검토
요인 구조 EFA에서 3축 또는 6하위축 구조가 해석 가능해야 하며, CFA에서 대안 모형보다 적합해야 한다. 불일치 시 8유형 구조를 유지하지 않는다.
수렴 타당도 관련 외부 척도와 예측 방향이 맞아야 한다. 예: 원칙 성향은 규칙·의무 관련 척도와 양의 관련. 방향이 다르면 축 명칭 또는 문항 해석 재검토
변별 타당도 서로 다른 축이 지나치게 같은 점수처럼 움직이지 않아야 한다. 과도한 상관은 문항 독립성 문제로 처리
준거 타당도 내부 신고 의향, 적극행정 의향, 절차 준수 태도, 행동 시나리오 선택 등과 사전 가설 방향의 관계를 보여야 한다. 관계 없음이면 진단 도구 주장을 보류
공정성 직급, 직무군, 성별, 연령대, 기관 유형별 측정 동치성(measurement invariance)을 점검한다. 불일치 시 집단 비교 금지

의사결정 게이트

결과조치
3축 구조가 재현되고 준거 타당도가 예상 방향으로 확인됨 타당화된 성향 척도 후보로 격상하고, 결과 화면 개편을 검토한다.
축 일부만 안정적임 안정적인 축만 연구용 점수로 사용하고, 불안정한 축은 자기성찰 설명으로 제한한다.
3축 구조가 재현되지 않음 8유형 구조를 검증 주장으로 사용하지 않고, 문항 또는 이론 모형을 재설계한다.

8. 점수 체계 개편 방향

현재 앱의 8유형은 3개 순점수의 부호로 결정된다. 과학적 도구로 올릴 때는 이 방식만으로는 부족하므로, 유형보다 축 점수와 결과 안정도를 앞세운다.

  • 각 축은 원점수, 표준점수, 백분위를 함께 산출한다.
  • 0 근처 또는 신뢰구간이 축 중앙을 포함하는 경우 "경계형"으로 표시한다.
  • 8유형은 대표 이름이 아니라 프로파일 라벨로 취급한다.
  • 레이더 차트용 제곱근 정규화는 "시각화 점수"로 분리하고, 연구 분석에는 원점수 또는 표준화 점수를 사용한다.
  • 점수 해석 문구는 "좋다/나쁘다"가 아니라 상황별 강점과 취약 조건으로 작성한다.

10. 문서 관리 규칙

  • 이론 문헌 검토는 docs/research/의 축별 문서에 추가한다.
  • 실행 계획, 검증 상태, QA 리스크는 이 문서의 표를 갱신한다.
  • 문항 설계 원칙은 test-design-playbook.html과 question-review-prompt.html에 반영한다.
  • 점수 계산이나 결과 표현이 바뀌면 scoring-and-validity.html도 함께 갱신한다.
  • 원자료, 로그, 분석 코드 파일은 허브의 기본 카드로 직접 노출하지 않고, 필요하면 별도 HTML 요약 문서로 연결한다.
