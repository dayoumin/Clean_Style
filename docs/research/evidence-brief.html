Clean Style 과학적 근거 요약

외부 공유용 요약 문서다. Clean Style은 현재 "타당화된 진단검사"가 아니라, 청렴 의사결정 상황에서 자신의 판단 경향을 돌아보게 하는 자기성찰 도구다. 다만 3축 구성과 문항 설계는 기존 윤리·성격·조직행동 연구에 기반하며, 향후 표본 기반 타당화 계획을 갖고 있다.

근거 수준 1이론적 기반 있음
근거 수준 2문항·계산 로직 검토됨
근거 수준 3표본 기반 검증은 진행 전

한 문장 설명

Clean Style은 공공·연구기관 업무에서 자주 만나는 청렴 딜레마를 바탕으로, 사용자의 판단 경향을 원칙-유연, 투명-신중, 독립-협력 세 축으로 정리하는 자기성찰형 성향 프로파일이다.

외부 설명 권장 문구: "이 도구는 공식 인사평가나 선발용 검사가 아니라, 청렴 의사결정 방식에 대해 대화하고 성찰하기 위한 교육 보조 도구입니다."

과학적 근거는 어디에 있나

구분근거현재 판단
3축 모델 윤리풍토 이론, 도덕 발달 이론, HEXACO, Schwartz 가치 이론, 대인관계 원형모델 등에서 관련 차원이 반복적으로 논의된다. 이론적 근거 있음
시나리오 문항 연구비, 계약, 보고, 공동저자, 외부 미팅 등 실제 공공 연구기관 업무 상황을 기반으로 응답을 구성했다. 맥락 적합성 있음
점수 계산 답변별 축 점수 매핑, 3축 순점수 계산, 8개 프로파일 도출 로직이 코드와 테스트로 관리된다. 계산 일관성 있음
심리측정 검증 응답 표본을 이용한 신뢰도, 요인구조, 준거 타당도, 재검사 안정도 검증은 아직 수행 전이다. 검증 필요

세 축의 이론적 배경

원칙 ↔ 유연

규칙·기준을 우선하는 판단과 상황·맥락을 고려하는 판단의 긴장을 다룬다. 도덕 발달 이론, 윤리적 입장 이론, 조직 윤리풍토 연구에서 규칙 준수와 상황 판단의 차이는 반복적으로 다뤄진다.

투명 ↔ 신중

즉시 공유·보고하려는 경향과 충분히 확인한 뒤 판단하려는 경향의 긴장을 다룬다. 정직성, 신중성, 정보 공개, 리스크 관리 연구에서 공개성과 정확성 사이의 균형이 중요한 문제로 다뤄진다.

독립 ↔ 협력

혼자 판단하고 실행하는 경향과 함께 논의하고 합의하는 경향의 차이를 다룬다. 성격심리학, 개인주의-집단주의 연구, 대인관계 원형모델, 내부고발과 조직 순응 연구에서 관련 근거를 찾을 수 있다.

현재 결과를 어떻게 해석해야 하나

해석 가능해석 금지
이번 응답에서 어떤 판단 경향이 상대적으로 두드러졌는지 개인의 청렴성 수준이 높거나 낮다는 판정
청렴 딜레마에서 어떤 강점과 주의점이 있을 수 있는지 인사평가, 선발, 승진, 징계 판단
팀 교육에서 서로 다른 판단 스타일을 토론하는 출발점 조직·직군 간 우열 비교

앞으로 보완할 검증

  • 전문가 검토로 문항이 실제로 의도한 축을 측정하는지 확인한다.
  • 파일럿 표본으로 문항 분포, 축간 상관, 문항 편향을 확인한다.
  • 본조사에서 신뢰도, 요인구조, 준거 타당도를 검증한다.
  • 2~4주 재검사로 결과 안정도를 확인한다.
  • 검증 결과가 충분하지 않으면 8유형은 설명용 프로파일로만 유지한다.
