## 1. 변경 이유와 결정된 범위

기존 선택지 중 일부는 유연함·신중함·협력이 규정 위반, 부실 처리, 책임 회피처럼 읽혔다. 반대로 일부 원칙 선택지는 ‘솔직하게’, ‘객관적으로’, ‘제대로’ 같은 표현 때문에 정답처럼 보였다. 결과 설명에도 특정 유형만 더 올바르거나 유능한 것처럼 읽히는 문장이 있었다.

이번 작업의 목적은 **기존 테스트의 표현과 채점 연결을 보수하는 것**이다. 모든 유형을 존중하되, 실제 행동을 돌아보게 하는 주의점까지 없애지는 않는다. 원칙 유형의 힘 있는 표현을 일괄적으로 약화하지 않고, 각 유형의 개성을 유지한다. 문항이 보려는 시간·예산 압박도 유지한다.

논의 과정에서 선택지당 단일 축 채점, 문항 전면 교체, 복수 유형 결과, 응답 수에 따른 판정 보류 등을 검토했으나, 변경 범위가 지나치게 커졌다. **사용자는 이 재설계안을 채택하지 않고 기존 구조를 유지하기로 결정했다.** 이 문서는 그 결정에 맞춘 최소 수정안만 포함한다.

### 유지할 사항

- 15문항, 문항당 선택지 4개, 기존 3축과 8유형 구조.
- 문항 ID, 문항 순서, 선택지 순서.
- 선택지 하나가 여러 축에 점수를 줄 수 있는 기존 구조.
- 선택지별 기존 `scores` 숫자와 점수 합산 방식.
- 기존 8유형의 ID·이름·연결 관계·이모지.
- 기존 8유형 판정 방식과 동점 처리.

### 변경할 사항

- 아래 두 표에 명시한 문구와 2절에 확정한 공통 안내 문장·표시 위치.
- 규정 위반처럼 읽히는 표현, 특정 선택지를 정답으로 만드는 표현, 과장된 결과 설명.
- 단순 위임을 공동 검토로 바꾸거나, 단순 문의에 상황 공유를 명시하는 등 기존 점수에 해당하는 행동을 드러내는 문구 보완.

**두 표와 공통 안내 명세에 없는 문구·기능·점수는 그대로 둔다. 이번 안에서 점수 숫자 변경은 제안하지 않는다.** 맞춤법이나 문체 통일만을 이유로 추가 수정하지 않는다. 이 문서의 ‘최소 수정안’ 열을 최종 적용 대상으로 삼고, 이전 대화나 이전 문서안의 다른 표현을 혼합하지 않는다.

## 2. 표 읽는 법과 공통 안내

- A·B·C·D는 현재 `choices` 배열의 첫 번째부터 네 번째까지다. 코드 배열 인덱스로는 각각 0·1·2·3이다.
- 실제 문항 화면은 선택지를 섞어 표시하므로, 화면의 A·B·C·D가 이 표의 A·B·C·D와 같다고 가정하지 않는다. 수정과 점수 확인은 원본 배열 인덱스를 기준으로 한다.
- 한 표의 같은 행에서 A·B 등의 표시는 기존 문구와 수정안을 서로 연결한다.
- ‘점수 유지’는 기존 설계 의도를 문장과 맞춘다는 뜻이다. 수정 전후 응답 비율이 같거나, 기존 채점의 과학적 타당성이 입증됐다는 뜻은 아니다.
- 아래 표는 변경 대상 부분만 적었다. 문항 전체나 유형의 모든 필드를 교체하는 명세가 아니다.

### 공통 안내 문장과 위치 — 확정안

다음 문장을 성인 테스트의 문항 화면에 표시한다.

> 관련 규정과 필수 절차를 지키는 범위에서, 내가 평소 가장 먼저 취할 행동에 가까운 선택지 하나를 골라 주세요.

- 대상 파일: `src/products/adult/pages/test-page.tsx`.
- 위치: 기존 `ProgressBar` 바로 아래, `QuestionCard` 바로 위.
- 표시 범위: 기본형·Plus의 성인 청렴 테스트 15문항 화면에서 공통으로 표시한다. 이어하기로 문항에 진입해도 보이게 한다.
- 표시 방식: 문항 내용과 구분되는 읽기 쉬운 본문 안내로 둔다. 작은 글씨로 축소하거나 접힌 영역·도움말 안에 숨기지 않는다.
- 홈 화면의 기존 ‘정답 없음’ 안내는 유지한다. 별도 테스트 시작 화면·모달·동의 버튼은 추가하지 않는다.
- 범위 경계: 학생·일터 존중 진단에 영향을 줄 수 있는 공유 컴포넌트의 전역 안내로 추가하지 않는다. 성인 테스트 페이지 안에서 처리한다.

홈에는 눌러서 보는 ‘정답 없음’ 안내가 있지만, `/test`는 별도 시작 화면 없이 문항으로 들어간다. 안내를 문항 화면에 두어 직접 진입·이어하기에서도 전제를 확인할 수 있게 했다. 구현 후 브라우저 배치 검증 결과는 6절에 기록한다.

```text
테스트 제목 · 이전 · 중단
진행 표시줄 (ProgressBar)
공통 안내 문장                ← 추가할 위치
상황 설명과 선택지 (QuestionCard)
```

현행 소스의 축과 부호는 다음과 같다. 축의 정의 자체를 이번 작업에서 재설계하지 않는다.

- `principle`: +는 원칙, −는 유연.
- `transparency`: +는 투명, −는 신중.
- `independence`: +는 독립, −는 협력.

## 4. 8유형 설명: 기존 문구 → 최소 수정안 → 채점 영향

**8유형의 이름은 모두 유지한다.** 아래에 적지 않은 설명·강점·주의점·팁도 그대로 둔다. 주의점을 전부 부드러운 칭찬으로 바꾸지 않고, 실제 행동을 돌아보는 기능을 유지한다.

## 5. 다른 AI에게 전달할 작업 지시문

다음 지시문은 이 문서의 두 표와 함께 사용한다. 이전 대화를 읽을 필요는 없다.

### 작업 목적

Clean Style의 기존 성인 청렴 스타일 테스트를 전면 재설계하지 않고, 문항과 결과 설명의 표현을 최소한으로 개선하려는 작업이다.

기존 선택지 일부는 유연함·신중함·협력이 규정 위반, 부실 처리, 책임 회피처럼 읽히고, 다른 선택지는 정답처럼 보였다. 이번 수정은 그런 불균형을 줄이되 기존 검사 구조와 유형명을 유지하려는 것이다.

사용자는 문항 전면 교체와 채점·판정 체계 재설계를 채택하지 않았다. **이 문서는 여섯 곳 보완과 공통 안내 위치까지 반영한 최종 전달 명세다. 최초 문서 작성 단계에는 코드 반영이 제외되어 있었으나, 2026-10-15 후속 사용자 지시로 이 명세의 구현과 검증이 승인되었다.** 반영된 내용을 중복 적용하거나 이번 범위 밖으로 변경하지 않는다.

### 기준 소스와 작업 경계

1. 프로젝트는 `D:\Projects\Clean_style`이고, 기준 소스는 `src/data/questions.ts`다.
2. 실제 작업 전 최신 소스와 저장소의 `AGENTS.md`를 확인한다. 필요한 경우 대상 폴더의 하위 지침도 확인한다.
3. 현재 소스가 이 문서의 ‘기존 문구’와 다르면 최신 상태를 대조하고 차이를 알린다. 다른 작업자의 변경을 덮어쓰지 않는다.
4. 기본형·Plus가 공유하는 성인 청렴 문항·결과 설명과 2절에 명시한 성인 테스트 안내만 대상이다. 학생 제품, 학생 문항, 일터 존중 진단은 변경하지 않는다.
5. 문구 대상은 `src/data/questions.ts`, 공통 안내 대상은 `src/products/adult/pages/test-page.tsx`다. 별도 승인 없이 홈 화면이나 공유 `QuestionCard`의 전역 동작을 바꾸지 않는다.

### 유지할 사항

- 15문항과 각 문항의 선택지 4개.
- 문항 ID, 문항 순서, 선택지 순서.
- `principle`, `transparency`, `independence`의 기존 정의와 점수 합산 방식.
- 선택지 하나가 여러 축에 기여할 수 있는 구조와 기존 `scores` 숫자.
- 다음 8유형의 ID·이름·연결 관계·이모지: 소신 수호자, 정의의 조율자, 묵묵한 파수꾼, 신중한 중재자, 실용주의 개척자, 열린 소통가, 전략적 해결사, 온건한 조정자.
- 기존 8유형 판정 방식과 동점 처리. 현재 소스는 축 점수가 0이면 각각 원칙·투명·독립 쪽 키를 사용하고, 별도로 동점 축을 기록한다. 이번 문구 수정 작업에서는 이 규칙을 바꾸지 않는다.

### 변경할 사항

이 문서 3절과 4절의 두 표 및 2절의 공통 안내 명세만 수정 대상으로 삼는다. 두 표의 ‘최소 수정안’ 열이 최종 문구다. **소신 수호자 설명은 원문 유지로 확정했으므로 수정하지 않는다.** 안내는 성인 테스트 페이지의 `ProgressBar` 바로 아래, `QuestionCard` 바로 위에 표시한다. 배치 위치를 홈 또는 별도 시작 화면으로 다시 선택하는 작업은 하지 않는다.

최종 검토에서 확정한 보완은 다음 여섯 곳이다. 실제 적용 문구는 두 표를 따른다.

1. 15번: “대충 사인만 해달라”는 요청과 마감 압박을 유지하고, 상황의 ‘내일까지인’을 ‘내일 마감인’으로만 다듬는다. 선택지 B·D 보완은 유지한다.
2. 3번: 연말 반납 압박을 유지하되 모든 연구비가 아니라 ‘이 과제’의 조건으로 명시한다.
3. 6번 B: 기존 업체의 납기·품질 장점을 고려하는 원래 고민을 남긴다.
4. 12번 D: 개인을 특정하지 않는 가벼운 문의로 두되, 관찰한 처리 방식과 의문을 설명한다는 점은 유지한다.
5. 소신 수호자 설명: 원문을 유지한다.
6. 묵묵한 파수꾼 강점: ‘올바른 방향’을 ‘기준’ 중심으로 고치고 원문의 힘 있는 표현을 유지한다.

9번의 각자 비용 부담 조건과 C의 ‘기관 기준에 어긋나지 않는 범위에서’는 모두 유지한다. 비용 조건을 분명히 하는 것과 만남의 적절성을 일반적으로 보장하는 것은 구분한다.

‘상급자에게 결정 위임’을 ‘함께 검토’로, ‘일반적인 규정 문의’를 ‘상황 공유와 규정 확인’으로 바꾼 것은 기존 협력·투명 점수에 해당하는 행동을 문장에 명확히 드러내기 위해서다. 점수 체계가 새로 검증되었다는 뜻은 아니다.

표에 없는 문구는 맞춤법이나 문체 통일만을 이유로 추가 수정하지 않는다. 유형의 주의점을 모두 없애거나 칭찬으로 대체하지 않는다.

### 반영하지 않을 이전 제안

- 선택지마다 한 축만 채점하는 방식.
- 축별 최소 응답 수, 2배 차이 등 새 판정 문턱.
- 두 유형·네 유형·전체 판정 보류 결과.
- 답변 하나 변경에 따른 민감도 점검을 새 결과 기능으로 추가하는 안.
- 커피 제안인 9번을 인수인계 상황으로 교체하는 안.
- ‘든든한 조율자’, ‘지혜로운 해결사’, ‘따뜻한 조정자’ 등 유형명 변경.
- 새 통계 수치를 검사 타당성이나 실제 사용자 유형 분포의 근거로 사용하는 것.

### 확인할 사항과 완료 기준

- 문구만 바꾼 경우, 동일한 답안 배열의 점수와 유형 결과는 이전과 같아야 한다.
- 문항 ID·순서·선택지 순서·`scores`·유형 ID·이름·연결 관계·이모지가 유지됐는지 확인한다.
- 두 표와 2절의 공통 안내 명세 밖으로 문항·필드·제품·화면 변경이 확장되지 않았는지 확인한다.
- 소신 수호자의 설명이 원문 그대로인지, 여섯 곳 보완이 표의 최종 문구와 일치하는지 확인한다.
