  • C는 현재 비교판이므로 개별 투명 파일과 나머지 상징이 필요합니다. 기존 artwork.ts의 8유형 연결 구조는 재사용할 수 있습니다.
  • prepare-adult-artwork.mjs는 현재 WebP만 생성합니다. PNG까지 함께 출력하도록 보완해야 화면·공유 스타일이 일치합니다.
  • 학생 배포 확인은 옛 준비 문구를 찾고 있어 현재 시연 화면과 맞지 않습니다. TODO에 등록했으며 학생 배포 전에 갱신해야 합니다. 실제 배포 실패 관찰이 아닌 소스 불일치 확인입니다.
  • 공통 통계의 운영 의도와 Worker의 실제 Luna 선택은 출시 QA에 기록했습니다. 기본 배포의 토큰 검사는 대체 모델도 통과하며 Plus 검사는 홈 HTTP만 확인합니다.
