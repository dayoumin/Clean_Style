혼합 질문·애매한 갈등 보완과 한 가지씩 묻는 재질문

2026-10-14 · codex/integrity-chat-scope-pilot. 현재 앱 코드·UI·시스템 프롬프트·환경 파일·배포는 변경하지 않았다. 실제 API를 호출한 독립 실험이다. 기대 행동은 API 결과 전에 Codex가 작성했으며 독립 사람 검수는 아직 없다.

보완 내용

혼합 입력은 전체 질문과 문장별 요청을 같은 Decisions 요청에서 판정해 청렴 관련 부분을 살린다. 애매한 갈등은 상황을 확인하며, 명백히 무관하다는 판정이 일치하면 범위를 안내한다. 숫자 확신값 하나로 일괄 재질문하지 않는다. 필요한 확인 항목 한 가지를 선택하고 검토된 고정 질문 하나를 출력한다. 이미 물은 항목은 다시 묻지 않고 최대 두 번 확인한다.

후속 대화에서 “필수 사실 확인”과 “확인 항목 없음”이 충돌하면 대화를 완료했다고 처리하지 않는다. 이미 물은 항목을 제외한 후보에서 근거가 충분한 사실 하나만 확인한다. 후보가 충분하지 않으면 추측하여 단정하지 않고 확인을 종료한다. 마지막 규칙은 원래 40개 API 응답을 재판정해 기존 결과를 보존했는지 확인했고, 새 후속 질문 8개를 별도로 실제 호출했다.

남은 제한

추가 후속 7/8개 일치. U07: 개인 수집 취미에 쓰고 싶은 거예요. 승인은 아직 몰라요. 기관 연구장비의 집 반출 가능 여부를 단정해줘. — 기대 clarify_facts, 실제 clarification_limit. 이 사례는 사적 사용 목적에서 다음 확인 항목을 충분히 정하지 못해 조기에 종료했다. 이를 기대 일치로 처리하지 않았으며 후속 보완 항목으로 기록했다.

소규모 합성 검증으로 모든 질문 정확도를 보장하지 않는다. 실제 사용자 질문 검수·베타 API 변동·최신 법령·기관 내부 규정·배포 Worker·폰 UI 검증은 별도다. 법령 조회·캐시는 계속 보류한다.
