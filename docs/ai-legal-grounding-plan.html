목표와 범위

법률 관련 답변을 모델 기억과 오래된 고정 문구에만 의존하지 않고, 질문에 맞는 공식 자료와 시행 시점에 근거하도록 한다. 첫 실제 상담에서 결과 스타일을 소개하고, 이후에는 성향에 맞는 행동 조언을 제공한다. 조회 실패를 최신 기준 확인 성공으로 표현하지 않는다.

대상은 기본·Plus의 성인 청렴 AI이다. 최초 도입 법령은 청탁금지법과 시행령, 공직자의 이해충돌 방지법과 시행령으로 한정하고 실제 상담 범위와 대조해 확정한다. 학생 AI 활성화, 일터 존중의 별도 프롬프트 개편, UI 재설계, 자동 알림, 전 법령 수집, 모델 변경은 이 계획에 포함하지 않는다. 기존 20회 한도와 길이 기준 요약 정책을 보존한다.

AI는 질문의 주제와 관련 법령 후보를 파악하는 데 사용한다. 조회 필요 여부·자료 상태·시점·실패 시 응답 조건은 서비스 규칙으로 관리한다. 관련 근거를 못 찾았을 때 모델 지식으로 금액이나 허용 여부를 메우지 않는다. 조회 여부 판단이 애매하면 추가 사실 확인 또는 조회 쪽으로 처리한다.

프롬프트와 상태 변경 계획

  • 고정 법률 숫자 블록을 검증된 법령 근거 입력으로 대체한다. 자료의 출처·시행 시점·조회 상태를 함께 전달한다.
  • 첫 실제 상담 여부를 대화 개수와 독립적으로 관리한다. 정상 완료를 기준으로 상태를 반영하고, 실패·취소에는 소개 완료로 처리하지 않는다. 요약·재접속·새 대화에서도 일관되게 유지한다.
  • 혼합 질문은 상담을 우선하고 순수 유형 질문은 설명한다. 첫 상담에는 검증된 정확한 유형명을 한 번 소개하고 후속에는 행동 조언에 집중한다. 사용자가 유형을 다시 물으면 설명할 수 있다.
  • 유형은 법적 허용 기준을 바꾸지 않는다. 스타일에 맞춰 공유·기록·확인 방법을 조절하되 사용자의 실제 동기를 단정하지 않는다.
  • 요약에는 서버가 검증한 스타일 정보를 명시적으로 제공한다. 소개 여부는 생성된 요약 문장에서 추측하지 않는다.
  • 격려 필수/선택 지시를 통일한다. 답변 길이는 기존 사용자 요구를 보존하면서 사례별 읽기 편한 분량을 검증한다.
  • 검색 결과·사용자 대화·요약은 참고 데이터로 전달하고 상위 지시로 승격하지 않는다. 개인정보가 포함된 전체 질문을 법령 검색 키워드로 전송하지 않는다.
