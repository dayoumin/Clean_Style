# Clean Style product context

This repository composes three products from one main branch. Adult Clean Style is a short Korean workplace integrity self-reflection experience: 15 situations, eight descriptive styles, a six-direction display, optional result-sharing name, saved local result history, and optional AI advice. It is not a moral grade or a clinical diagnosis.

Clean Style also includes diagnostic-owned workplace-respect flows and safeguarding, reached from the home screen's top-right icons (the former Plus product was merged into it). Clean Style Student is a separate instrument with no adult questions, adult results/history, name entry, or AI chat.

The current design task covers the adult public experience. The user chose concept B: light, warm, mint/sky colors, generous mobile spacing, soft illustrations, and one small fish plus a seaweed point on the home illustration. Color may change later. Preserve questions, scoring, interpretation, progress/resume, optional name behavior, sharing, history, and AI conversation controls. The user requested independent agent review before proceeding.

The user selected illustration style C (2D line drawing) on 2026-10-14. Keep the B screen composition and palette, and replace the adult illustration family consistently. The adult product owns these integrity assets; workplace-respect interpretation and student visuals remain diagnostic-owned. See `docs/adult-c-illustration-plan.html` for the approved scope and review sequence.

Mobile is the primary use scene; desktop retains the narrow centered app frame. Never deploy without a request in the current task. Preserve unrelated ongoing student changes.
